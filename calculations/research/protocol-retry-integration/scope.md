# C68 QUIC HRR／Retry／PSK 公共接入范围

本次交付将已冻结的 research/protocol-retry 候选接到公共 Python 包、可编辑输入、CLI、统一复算与第十二章。它补全的是有限 QUIC 声明消息分支，不关闭整个 C68。

输入为声明的消息长度、CRYPTO/token预算、双向速率、传播、业务字节、模型时间和独立授权；来源为既有七份固定官方 RFC。输出逐包时间、PN/STREAM范围、密钥/CID变化、反放大预算、唯一有效业务与全部已建模发送字节。真实密码验证、完整编码与未建模网络行为不由这些输出推断。

验收要求：20个候选完整数学及逐包字段与公共接口一致，仅固定来源注册元数据可不同；40次实际JSON/Markdown CLI与40份冻结产物一致；专项手算不变量与全项目tests通过；统一reproduce、图表来源、结果校验及正文网页通过。check-public.py 的来源根字段首次写成 source_root，实际字段为 reference_source_root；纠正比较器后重新跑全20场景，未放宽数学字段比较。

C68仍缺TCP上的HRR/PSK回退、运行时重复或空token Retry及组合分支、后台票据、完整编码、一般ACK/PTO/丢失/拥塞/流控，以及语音、截图、媒体截止和多流。全局目标持续，局部公共验收不是全书完成。
