AKG 讲解顺序：原始矩阵乘接激活循环 → split／tile → reorder → 计算位置与缓存 → 归约完成后融合 → 依赖箭头与非法提前激活反例 → 多面体编译如何表示并组织这些选择。循环 fuse 与算子融合分开；Halide／TVM API 是理解入口，不能代替 AKG 论文中的实际机制。形式依赖合法、数值满足要求、性能改善分别检查。

核心实验由 5-2／5-4／5-9 改为 5-2／5-8／5-9。实验 5-9 使用配套已验证候选与记录，无需先完成 Agent 实验；5-8 核心部分可读配套 trace，persistent 实跑为选做。9 项实验、8 项图号保持，全部原扩写计算与来源保留；正文减少的说明可查本次原文快照。第 5 章仍为 5 节、17 小节。
