# 表格恢复竖向连续排版

取消所有 landscape 页面及 table 浮动体。现有 90 张表均以普通正文宽度排版，短表标题与表体保持在一起，不强制分页或独占一页；超过 12 行的后续表格保留 longtable 自动跨页能力。

列间距从 4 pt 减为 2.5 pt，列宽总和留出 1% 余量。模型矩阵表按内容分配列宽，其他表格均分可用空间。中文自动换行，单元格中的原生数学可在乘号、箭头、加号和等号后换行，不缩放公式或横向拉伸文字。
