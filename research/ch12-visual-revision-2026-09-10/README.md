# 第十二章段落衔接与直观配图

本轮处理段落之间的逻辑跳跃，以及数字密集但缺少示意的小节。此前正文、构建器、校验器和阅读说明保存在 `before.tar.gz`。

## 衔接调整

段落过渡围绕前一个比较留下的问题展开：单张截图每次重新编码 → 多轮缓存命中 → 保存语言 KV → 搬移会话；一次会话迁移 → 运行中逐层通信；连接已复用 → 窗口仍限制发送 → 确认释放窗口但自身也占带宽；两路共享出口 → 共同设备故障；正常时缓存节省计算 → 故障时提交记录节省重做 → 用失败概率计算平均费用。

图旁补充具体的阅读方法：比较条带终点、沿箭头追踪依赖、看缓冲曲线的起点与斜率、找迁移收益越过零线的位置、观察已提交的轮次。

## 数据修正与验证

绘制分块图时重读原计算事件表，发现三块输出为 1、2、2 MB，并非等大。已将正文的平均回传约 0.13 秒改为 0.08、0.16、0.16 秒，保持与来源的 12.36 秒结束时间一致。科学来源未改。

固定窗口图的 64 KB 在 20 Mbit/s 上发送需 25.6 ms；整批反馈采用发送结束后 100 ms 返回，因此一周期 125.6 ms。图注明确这一机制与正文 W/R 上界的关系。部署组成图按类别汇总二十轮时间，不把类别顺序解释为实际逐轮时序。

校验覆盖十六图顺序、所有引用、外部图注、来源与产物哈希、新图算式、布局和公式。浏览器检查桌面与手机。最新结果保存在 `manuscripts/ch12/validation.json`、`math-validation.json`、`browser-validation.json`；配图总览已更新。

阅读版新增点击或键盘打开插图放大的功能，大图可滚动查看，关闭后返回正文。浏览器检查同时验证大图加载和关闭。最终内容校验 342 项通过，99 处公式解析通过，桌面 1440 px 与手机 390 px 显示检查通过。
