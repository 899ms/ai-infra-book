# 全书图文与术语审查

本轮覆盖前言和十二章的 410 幅图，逐图检查图内标签、图例、图注及相邻正文。对修改后的 59 幅图检查了渲染结果，并抽查了 PDF 中连续图组与解释段落的分页。没有将这项审查扩大为对全部实验结果或模型事实的重新验证。

## 修改

- 统一上下文、输入、输出的 token 计数，区分 token 数与位置索引。保留位置编码、内存地址、部署位置等有明确含义的用法。
- KV 分页说明分别使用“可保存多少 token 的 KV 空间”“未用 KV 槽位”和“物理块”，避免把 token 数、槽位和地址混写成“位置”。
- 视觉编码使用“视觉 token”，说明其为图像块合并后的特征向量；压缩与稀疏检索使用“缓存条目”，避免与文本 token 混淆。
- 澄清每请求容量、每步访问量、每输出 token 分摊量、时钟周期与离散时间单位。加速器专用图中残留的“设备”改为“加速器”，保留播放设备及广义 UB 设备等用法。
- 为多图对比补充各图的配置、颜色、符号或缩写说明。本轮修改 84 处图注；例如 TP=2/4/8 的实例组成、A/B/C/D 配置、圆圈与叉号、Full/Reindex/Reuse 的缓存条目选择。
- 第七章“下一图先搬回本地”修正为“下半图先搬回本地”。为九处连续图组补入局部承接段落，明确当前图与前一方案的关系。
- PDF 浮动排版在图后设置边界，使解释正文不能越过尚未排出的图。图片仍可以移到下一页。

## 核验

- 410 幅图均能映射到 PDF 图注。
- 初次扫描找到 17 幅图与相邻解释片段相隔超过一页；最后一次扫描未发现这种情况。该检查依据能够匹配的文字片段，并不等于所有图与完整讨论都必须在同页。
- 重绘图使用原有配色与字号规范；图内最小字号不小于 11 pt，画布边界检查通过。
- PDF 字体嵌入、页面文字边界、缺字、溢出、未定义引用检查通过。网站页面、搜索索引、内部链接与图片检查通过。
- 旧验证脚本中 `new_200k_figure` 的固定数字匹配仍未通过；该项在本轮开始前已经失败，未为通过检查而改动书稿数值。其余 PDF 检查通过。
