# 前三章：从结构推导需求，再据此作出选择

本轮先完成 [51 个小节的设计表](section-design.md)，再重写正文、调整配图和 23 项练习。设计表逐节列出问题、新引入的关系、例子、条件变化及编辑动作。修改范围为前三章正文及其生成、验证文件。

第一章建立容量、运算量、接口读写量与执行时间之间的联系，用批大小的变化推导计算与读取的转折。第二章从线性层、位置对、历史状态与专家分派，逐步组装完整模型需求。第三章把单次调用放回请求到达、工具依赖、训练更新及长期服务中，推导积压、状态寿命和成本选择。

四个主模型的完整表保留在正文，V3 保留为历史参照；总体架构表并列隐藏维度、层数、专家总数及每 token 选中数。数学表达使用 LaTeX，数据出处留在脚注及配套材料中。练习要求读者先预测、再代入、最后解释条件变化为何改变结果。

当前配图总数为 35：第一章 8、第二章 15、第三章 12。本轮新增 batch 转折图与工具依赖／状态寿命图，并调整现有配图的数学标签、正文引用与阅读顺序。图形由本地绘图程序生成，保存 SVG 和 PNG；数据来自已有计算和实验记录，以及明确写出的教学条件。
