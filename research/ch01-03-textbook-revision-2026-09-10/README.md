## 计算与复现

V4 新增的是同一公共分析器的一个场景，不是 GPU 测量：

```sh
python3 calculations/calc.py v4-forward --model deepseek-v4-flash --batch 1 --tokens 1 --history 8192 --format json --output manuscripts/ch02/comparison-v4-decode.json
python3 manuscripts/ch02/compare_models.py
python3 research/ch01-03-textbook-revision-2026-09-10/check_revision.py
```

`model-comparison.json` 保存各模型来源哈希和未取整整数。参数分组守恒；Qwen3.6 prefill 使用已有 last-head 场景，避免把 all-head 的 60.43 TFLOPs 混入末位置比较。K3 主比较采用 compact MLA；完整短请求延伸继续保留原 expanded 记录并明确范围。不同模型的有效因果／矩形／块式算法工作在表下注明。

校验入口：各章 build.py、第二章 verify_tables.py／verify.py、第三章 verify.py，以及本目录 check_revision.py／check_browser.py。`verification.json` 包括修订后核心练习的数值参考；完整文字与质量判别仍需读者解释。`browser-review.json` 记录当前 HTML 的哈希和浏览器检查，截图在本目录。
