# 第七章段落衔接与图示修订

本轮覆盖六节、23 个小节，重点是补全相邻段落之间的因果、比较和问题递进关系，并把数字推导对应的传输路径、时间关系与资源占用画出来。

## 论述组织

从归约流量进入 TP／PP 的交接方式，再由专家接收端的共享入口过渡到多网卡发送路径。远程访问先区分独立请求并发与同一快照复用，再计算维持链路吞吐所需的请求数。请求占用时间进一步引出缓冲区寿命、状态共享、顺序和回收。端点回收不足造成的等待延伸到网络队列，依次讨论错峰、实时反馈、多路径和循环资源依赖。章末将这些因素放在训练步的同一时间轴上比较，再解释小消息为什么应优先缩短启动。

正文不仅引用图号，还说明怎样沿图观察：沿流水线相同编号看微批推进，沿分叉与汇合处计算流量，沿橙色条带观察传完后仍占用槽位的时间，沿收包点与交付点之间的线段观察等待缺口。整步图放在重叠模型之后、数值比较之前，供后续推导反复使用。
