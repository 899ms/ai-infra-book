# 历史归档

本目录保存成书过程中的资料，供追溯设计与修订使用。当前阅读入口为[仓库首页](../README.md)和[十二章正文](../manuscripts/README.md)。

| 路径 | 内容 |
| --- | --- |
| [outlines/](outlines/README.md) | 旧写作大纲、章节安排与扩写材料 |
| [reviews/](reviews/) | 历次审阅、修订说明、修改前快照与检查结果 |
| [AGENT_COORDINATION.md](AGENT_COORDINATION.md) | 早期写作任务的协调记录 |

这些材料可能包含旧章号、旧结论与当时的本机路径，不作为当前正文或发布状态的依据。修改前快照、原始记录与哈希保留其历史含义；移动目录后的链接修复不代表重新执行实验。旧快照中的路径可结合 Git 历史查看。

网站导航直接从 `manuscripts/` 生成，不展示历史大纲。大纲仍供计算项目的历史证据同步与审计工具使用。专题调研、参考来源和实验原始数据保留在各自目录，维持正文证据链。

根目录原有的 `tmp/`、`output/` 与 `.obsidian/` 已退出版本控制；本地副本保存在被忽略的 `build/local-before-publication/`。正式发布使用构建工作流生成的产物。

历史工具 `scripts/verify_outline.py` 仍可用于检查归档，但不作为发布门槛：归档大纲已有章节结构、图号与扩写材料不一致。此次整理前后对照，38 项结构类报错一致；当前发布检查以正文网站构建、链接检查和 PDF 工作流为准。
