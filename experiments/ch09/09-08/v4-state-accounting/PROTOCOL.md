# V4 checkpoint state accounting on the recorded Agent shape

This is a local analytical replay, not a V4 model execution. The twelve recorded Qwen Agent requests supply their token counts and chained prefix-page identities as a fixed workload shape. They are not asserted to be V4 tokenizer outputs. Use the repository's pinned V4-Flash inference configuration and state implementation, without changing calculations/.

At each 16-token prefix endpoint count every backbone layer's BF16 window, completed compressed entries and CSA index entries, plus the full FP32 main/index compressor buffers. Include CSA's preceding overlap group, even at a completed group boundary. A complete checkpoint also requires position, model/config identity and prefix identity metadata; metadata, allocator padding, weights, MTP and temporary activations are excluded from logical tensor bytes. The serializers must explicitly capture nonpersistent buffers: an ordinary parameter state_dict is insufficient.

Compare full snapshots every turn, periodic snapshots at turns 4/8/12, and recomputation. Snapshot budgets are 0/16/32/64 MiB in a single durable tier. Store immutable complete snapshots, evict oldest to fit, and skip snapshots larger than budget. Before EVERY request discard volatile state to isolate recovery cost. Also compare invalidation of every stored snapshot before turn 7. These policies complement the existing four-tier dense-page replay; they do not model native V4 eviction.

Restore the longest stored endpoint whose entire recorded chained-page prefix matches the request. Read its complete tensor payload and recompute input_length minus restored_length positions. Write a new snapshot after processing the input if scheduled and it fits. Snapshot endpoints exclude the final incomplete 16-token page; this is a declared checkpoint policy, not a V4 requirement. No deduplication or incremental snapshot encoding. Save/restore times remain null: Qwen direct-I/O and remote page latencies cannot establish V4 execution or serialization latency.

The endpoint state must be captured while execution passes that endpoint, before processing the remaining tail, then published after the request. It cannot be reconstructed by truncating the final window/compressor buffers. This is an analytical capture contract, not an implemented V4 serializer; transient capture memory and metadata bytes are outside the retained tensor budget.

Also report the number of active uncompleted compressor positions and retained CSA overlap positions per layer at every endpoint. Those positions are not independently reconstructible from compressed history: missing window or compressor state invalidates this complete-snapshot contract. A separate history-only contract falls back to full input recomputation; it must not claim that replaying merely N mod ratio tokens suffices without the necessary earlier layer state.
