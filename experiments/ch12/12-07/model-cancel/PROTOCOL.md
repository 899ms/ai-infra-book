# Fish Speech HTTP close versus model completion

Run an isolated copy of the recorded Fish Speech wrapper against the same cached1.5 checkpoint on RTX. No enrolled/reference voice. Compile false is explicit; these timings do not compare against the earlier compiled service. Use loopback HTTP so both client and server events share one monotonic clock. This measures the backend cancellation boundary, complementing the existing two-host Queqiao fixed-audio cancellation experiment; it does not measure live TTS through Queqiao.

One short warmup, then three pairs of full/cancel requests, alternating order. Fixed long text and sampling parameters. Cancel after receiving44 header bytes plus1764 PCM bytes by setting SO_LINGER to zero and closing the connection. The server catches a broken pipe/reset when encountered; its generator is closed. Do not add cancellation support to the upstream worker. Observe semantic response-queue emissions through a forwarding wrapper, preserving the underlying queue. Synchronize CUDA before recording each emitted semantic chunk to distinguish completed model work from queued GPU submissions; this synchronization is instrumentation overhead and changes timing.

After every request wait for the semantic worker's natural `next` terminal response (up to180s), or record a timeout as an uncompleted observation. Record HTTP handler exit independently. Save complete and intentionally truncated response bytes. Worker errors fail the run. A client close or empty GPU allocator is not a model-cancellation acknowledgement. Report the number of semantic chunks completed after client cancellation, handler exit and terminal latency on the same clock. Never infer that HTTP disconnect terminates queued generation merely because output delivery has ended.

All service code, upstream semantic source, checkpoint config and software identities are hashed. Own HTTP server/process only; existing services are not modified. No acoustic output or microphone access.
