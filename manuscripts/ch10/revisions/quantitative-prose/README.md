# 第十章定量叙述修订

本轮沿用六节、23 小节结构，系统修改正文与九幅插图。正文采用“条件—计算—比较—结论—后续问题”的顺序；将版本、实现核验和证据范围留在脚注与配套，保留读者推导所需的假设。

主要改写包括设备下界、状态分片与重计算、梯度转换、流水调度、通信分桶、输入供给、检查点恢复、RL 阶段配比与权重交接、教师输出和完成期限。配置维度和整数边界保持精确，性能与容量按用途取有效数字。新增教学算例明确假设，没有增加 GPU 实测结论。

图 10-1 移出梯度转换路径；图 10-3 改为分片数与容量曲线；图 10-5 聚焦带宽与可用恢复点，周期损失改用正文表格；图 10-6 改为交接顺序与驻留量；图 10-7 移出记录容量。其余图精简画内条件，由外部图注承接。

before.md 与 build-before.py 是修订前的存档，供差异比较；存档正文的相对链接仍以原稿目录为基准，不作为独立阅读入口。请阅读 [当前正文](../../../10-训练系统.md) 或 [HTML](../../../10-训练系统.md)。验证结果见章节配套目录的 validation.json 与 browser-validation.json。
