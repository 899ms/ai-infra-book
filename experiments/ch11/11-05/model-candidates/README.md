## 资源节省是否抵得上等待

不要用各策略中位数之差当逐轮配对差。paired-comparison.json保存同trial配对：FIFO相对固定配额，A额外等待分别0.806156／0.594843／0.439104s，占槽节省分别−0.145800／0.095067／0.343809slot-s。第0轮既增加A等待又不省槽；其余两轮，若仅A训练组在等待，验证槽单价为Cv、训练等待每秒单价为Ct，则FIFO节省成本的条件分别Ct/Cv < 0.1598与0.7830。若B组也等待，则把B反馈提前的收益加入同一账本；没有实际价格不填虚构货币成本。

A优先相对FIFO三轮均提前A反馈（0.401570／0.206087／0.263112s），却推迟B反馈（0.415183／0.685318／0.565580s），并增加占槽（0.020396／0.473926／0.317037slot-s）。若两训练组的等待价格相同且都从候选就绪等待整批，B损失大于A收益，同时多占验证资源，因此本组三次均不支持总成本节省；只有A权重足够高才可能选择A优先。三次重复不能建立生产尾延迟或普遍性能排序。
