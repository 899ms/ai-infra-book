# 第十二章中文用词与句子润色

本轮合并处理两项要求：替换抽象、含混的用词，并逐段修改不自然的中文句子。修订前正文保存在 `before.md`，用词与句子修改分别记录在 `changes.json` 和 `sentence-changes.json`；其后又复查了图注、脚注和习题。

## 主要修改

- 按上下文将“候选”改成执行设备或部署方案。
- 将音频“供给／消费”分别写成生成、发送、到达、缓冲读取和播放，明确具体过程。
- 将泛指的“交接”写明为图片上传、特征传输、状态迁移或逐层通信。
- 重写“资源层／实际供给层”“重复支付交接”“消去共同工作”等抽象句式，解释实际计算、等待或比较的方法。
- 补全“模型约 30 ms”“发送服务为”等省略主干的表达，修正数值与动作之间的搭配。
- 统一操作编号、数据块编号等表述；保留拥塞窗口、流量控制、归约、缓存命中等技术术语。
- 改善图注、习题和脚注的句法；图内“接入空等”改为“接入等待”。

六节、20 小节、八道练习和七幅图保持不变。原计算与实验来源未修改。删去了一处重复的行内公式引用，其余公式及其含义保持一致。重新生成 HTML 和七图的 SVG／PNG／PDF，并检查公式、链接、来源与输出哈希以及桌面和手机显示。
