# 第四章段落衔接与配图修订

正文沿“工作量与数据量—硬件组成—执行与存储—数据到达和结果依赖—跨芯片传输—性能判断”递进。段间衔接具体说明上一项推导留下了什么问题，下一项机制怎样回答它。新增图前给出问题，图后解释形状、颜色或曲线对应的因果关系。

新增六幅图，全章共十四幅，图号与完整图题只出现在外部图注。图注交代配置、假设、单位及示意比例。流水时间线移至槽位推导前，使读者能够对照图形逐步检查数据就绪和计算开始时刻。

| 新增图 | 要建立的直觉 | 数值依据 |
|---|---|---|
| 4-1 权重复用 | 输入行增加，权重仍是同一份；每行分摊的读取减少 | 4096² 个 BF16 权重为 32 MiB，256 行分摊为每行 128 KiB |
| 4-3 专家输入 | 有效计算相同，分散成短矩阵后补零可能占大部分 | 512 次分派；256 × 16 行与 8 × 64 行 |
| 4-6 显存占用 | 固定占用先划走一部分，每条请求的 KV 再逐块填入 | 原权重结果、2 GiB 工作区、每个 8192 位置请求 1207959552 bytes KV |
| 4-8 子矩阵布局 | 有效数据很短，相邻有效区间的地址距离却很长 | 128 行，每行取 256 bytes，行步长 8192 bytes |
| 4-10 计算位置 | 计算放到权重旁边，链路便改为传输较小的输入和结果 | 32 GiB 与 64 MiB，同一 1 TiB/s 链路 |
| 4-13 时间曲线 | 增加行数时，计算时间线性增长，权重读取部分保持固定 | 同一 Q 投影，165.2 TFLOPs/s、1.008 TB/s，179 行处改变主导项 |

图由 [illustrations.py](illustrations.py) 与 [build.py](build.py) 生成，原始计算和实验记录保留不变。[verify.py](verify.py) 独立重算新增图的数据，检查整数边界，并校验正文图号、链接、公式、文件摘要和浏览器结果。
