# 全书例题标题、粗体提示与练习题干修订

本轮覆盖十二章正文的 505 处粗体文字，以及全部 106 项练习、实验。检查范围包括例题名称、段首提示、题目名称、题设与提问、跨段和跨节的案例指向。既有清楚的术语定义与标题保留。

## 修改原则与代表性改动

- 标题说明对象与问题。“固定八个 worker 的配比”改为“预填充与解码的资源配比如何决定吞吐上限？”，“十轮公共前缀”改为“跨轮缓存公共前缀能节省多少输入费用？”。
- 粗体提示说明具体内容。第四章重复使用的“问题”“推导”“结果解释”“改变条件”改为对应的比较对象、推导方法与条件变化；普通“解”“解答”改用正文格式。
- 题干明确动作、条件与待求量。“产生的 GiB·s”改为求状态占用量与保留时间的乘积；“设备边界”改为满足期限所需的最少设备数；分别说明两两比较、时间与容量、单阶段与完整任务。
- 跨段引用写出具体任务或章节，替换“回到……”等缺少信息的衔接。表示数据返回设备或数值恢复的正常用法保留。
- 练习 3-4 分成工具串行／并行与代码任务实测两段，明确两个工具都完成后模型才继续计算，并写明加速倍数所作用的阶段。
- 对行内粗体标题补齐与正文的标点分隔，避免 PDF 中标题末尾与正文连读。

以上要求已加入 `outlines/editorial-notes.md`。本轮在工作区既有修订之上进行局部修改，历史归档与既有技术修订保留。
