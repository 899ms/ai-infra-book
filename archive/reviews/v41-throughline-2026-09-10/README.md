# V4／V4.1 跨章会话修订

十二章围绕同一类 Agent 会话串联：等待工具、恢复状态、处理追加输入、继续生成。沿用第二章 8K 基线，128K 作为长度变体；新的时间参数均标明为教学假设。

[全书 PDF](../../../book/AI-Infra-Book.pdf) · [阅读入口](../../../manuscripts/README.md) · [新增图总览](new-figures-contact.png)

## 逐章修改

| 章 | 本轮推进的问题 |
| --- | --- |
| 1 | 将 V4→V4.1 定位为模型与基础设施协同的真实演进案例，交代后续会话路径。 |
| 2 | 保留作者新增表格与正确数值，澄清读取含 SWA、每步写入与容量增长、CED 的额外投影与近似恢复；展开共享和层级索引的自由度取舍。 |
| 3 | 输入密集 Agent 为什么推动 CED；8K 冷输入的专家矩阵 token 层数由 327680 降至 166400，但不作为总时延比例。 |
| 4 | FP4 主 KV、FP8 局部状态、MXFP4 兼容性与 RoPE 后量化的明确取舍。 |
| 5 | 共享容量与逐层读取不同；区分生产选择性读取与参考代码全索引打分后屏蔽。 |
| 6 | 共享状态跨设备时的复制、远程访问和放置代价；新版权重预算独立核算。 |
| 7 | 128K 全局 KV 在假设 25 GB/s 下的传输下界，及其与请求恢复时间的区别。 |
| 8 | 全部命中、仅全局命中、全局未命中三条恢复路径；长期缓存与短期 SWA；有界重放的质量对照。 |
| 9 | CED 改变阶段配比；缓存亲和路由与远端恢复的选择随队列长度翻转。 |
| 10 | 稀疏训练、QAT、候选域一致性与近似恢复分别验证，不把发布成绩当作结构消融。 |
| 11 | 工具环境与模型状态分别管理，固定轨迹下核算完整任务收益。 |
| 12 | 与固定权重思想实验衔接：权重免费和 KV 免费是不同条件，分别重新选择系统。 |

“候选池（candidate pool）”采用官方技术报告第 2.3.2 节术语；正文首次定义并引用 Figure 5，指可供注意力检索的位置，不指生成答案。

## 图与计算

六幅新图沿用 `figure_style`：420 pt 画布、至少 11 pt 标签、浅色填充、矢量线条、正文外置图注。包括跨层 KV 共享、层级候选选择、CED token 层数、驻留与逻辑读取、三条恢复路径、路由时间对照。[绘图源](../../../manuscripts/v41_case_figures.py)接入原章构建流程，SVG／PNG／PDF 均可重建。

[复算程序](../../../calculations/v41_throughline.py)读取已有缓存计算适配器与固定模型配置，输出[统一数据](../../../calculations/results/v41-throughline.json)。25 GB/s、8 ms 局部恢复、10／20 ms 排队均为教学假设；没有新增 GPU 性能或模型质量实测。

[图号映射](figure-renumbering.json)仅改正文图号与交叉引用，不改实验编号和原图文件名。修改前源文件及哈希保存在 `before/` 与 [清单](before-sha256.json)。大纲设计决定同步更新，来源锁仅更新本轮授权改变的大纲文件，见[记录](source-lock-updates.json)。
