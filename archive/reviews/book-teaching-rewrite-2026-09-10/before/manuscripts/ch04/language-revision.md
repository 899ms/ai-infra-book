# 第四章术语与中文表达修订

本轮通读七节正文，连同图注、表头、练习和章末小结一起修改。先检查术语，再逐段检查句子，重点处理主语缺失、修饰成分过长、名词搭配不当和直译。

| 原表达 | 修改方式 |
|---|---|
| 候选架构、加入候选 | 大纲中改为“可选的硬件架构”“纳入比较” |
| 输入服务、资源服务周期 | 具体写为“输入传输”“处理一个块所需的周期数” |
| 数据被消费、消费者 | 根据所指单元，改为“计算单元读取”“向量单元使用”“接收方” |
| 物化与重读 | “中间结果写回和重新读取” |
| 复用前史、捕获目标调用 | “此前重复使用同一份权重”“记录一次待测调用” |
| 冷内存模型 | 直接交代“假设输入和权重均从片外读取” |
| 活跃权重、tensor 工作量、lane | “本步所需权重”“矩阵运算量”“运算通道（lane）” |
| 形成闭环 | 写明用执行记录核对预计耗时，再分析差距 |
| 全年有效流量 | 写明设备按给定速率和利用率运行一年，并有足够请求 |
| 功率占用、计算趋近于零 | 分别改为消耗电能、计算时间趋近于零 |

保留有明确技术含义的标准术语，如算术强度、访存事务、归约、流水线、寄存器和缓存。对访存事务、输入槽、运算通道、GEMV 和 SIMD／SIMT，在首次使用处解释含义。避免用一个抽象名词代替具体的计算、读取、传输或等待。

公式、配置和原始实验结果保持不变。“1/16 的槽位”改成“16 行中只有一行”，表达的比例不变。正文全部引用地址经核对保持一致。另将例 4-1 中误写的“吞吐下界不变”改为“完成时间间隔的下界不变”，与前面的公式一致。

图中文字与正文同步。大纲中只修改两处“候选”的措辞，并更新本章记录的该文件校验值。原始 calculations、survey 与实验资料没有改写。
