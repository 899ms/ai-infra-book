## 后续写作沿用的术语规则

| 概念 | 统一写法与定义要点 |
|---|---|
| token | 首次写“词元（token）”，解释分词单位；后续可使用 token。token ID 是词元在词表中的整数编号 |
| prefill / decode | 预填充（prefill）处理已知输入；解码（decode）将输出逐步送回模型以继续生成 |
| context / context state | 上下文指模型可使用的输入与已生成内容；上下文状态是保存的 KV、递推矩阵或压缩表示。长度以 token 计，存储量以字节计 |
| KV cache / encoder cache | KV 缓存保存注意力的键和值；编码缓存（EC）保存编码器输出。两者对应不同的重算起点 |
| HBM | 高带宽内存；与 GPU 显存、主存、统一内存这些不同层面的名称分别解释 |
| TP / PP / DP / EP | 张量并行 / 流水线并行 / 数据并行 / 专家并行；定义时说明分别划分什么 |
| FLOPs / FLOP/s | 前者表示运算量，后者表示速率；G、T 分别表示十亿、万亿。具体峰值注明数值格式与稠密或稀疏条件 |
| GB / GiB | 分别使用十进制和二进制容量；首次使用说明换算，不混用计算结果 |
| FP16 / BF16 / FP32 / FP8 | 说明浮点格式及每元素位数。FP16 与 BF16 都占 16 位，但保留各自格式名称 |
| backpressure | 背压：下游无法及时处理时，使上游减速或暂停；释放空间时直接说清释放哪个缓冲区或请求资源 |
| RTT | 往返时间；传播、排队、处理的具体建模范围在算例条件中交代 |
| 安全上下文 | 通信认证与加密所维护的密钥、身份和会话状态；与语言模型上下文分别定义 |
| 专有模型、系统、格式 | 首次出现提供可识别的名称及用途；缩写用于后续叙述，代码标识符、原始数据编号和来源地址保持可追溯 |

定义放在首次实质使用处，表格和图提前引入概念时，在图表之前说明。跨章使用时补充与当前推导有关的简短回顾，不在每次出现时重复整个术语表。适用条件放在算例前或独立段落，不在段尾插入无关的自我否定。
