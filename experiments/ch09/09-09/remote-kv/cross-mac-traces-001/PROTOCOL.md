# Cross-Mac multi-turn recorded traces

Four recorded Chat turns and twelve recorded Agent turns; fixed inputs from trace-inputs.json, exact original source hashes retained. Separate fresh producer and consumer engines per trace, all on the single RTX PRO. Each turn generates exactly one token at temperature zero. Producer publication waits for every complete page in the reusable input prefix, identified by SGLang native chained SHA-256 token-page keys and model/TP suffix. Consumer recovers from the same Mac store via SSH. Per-turn barriers are instrumentation intervals, not original tool or user think times. No claim of task quality from these truncated outputs. Compare paired outputs, native device/host/storage counters, page integrity, and request/remote RPC timings; report request- and token-weighted hits separately. Single replay per trace; sample quantiles do not estimate a stable production distribution. First-write-wins retains conflicting payloads for inspection. This adds multi-turn remote measurements to existing routing records; it does not itself execute three remote-aware routing policies.
