# 术语与中文表达修订

将含义不清的简称按语境展开：一次完整前向、反向和优化器操作称为训练迭代；计算新参数称为参数更新；向生成端传递新权重称为权重同步。候选改为具体方案或保存间隔，锁页暂存改写为主机内存缓冲并解释页锁定内存，暴露通信改为通信等待时间，版本准入改为策略版本要求及过期样本筛选，样本身份改为样本标识。

随后逐段调整主语、动宾搭配、长句结构和连接方式，清理名词堆叠、英文直译语序以及术语替换后的重复修饰。图中文字、正文图注、习题和设计题说明同步修改。数据字段和计算公式保持原有语义。
