## 代表性修改

| 原表达 | 修改后的表达 | 原因 |
| --- | --- | --- |
| 状态寿命、状态存活时间 | 状态保存时间、状态需要保存多久 | 说明数据何时仍需保存 |
| 持久化内核（Persistent Kernel） | 常驻内核（Persistent Kernel） | 此处指持续运行并领取任务，不是写入持久存储 |
| 全宽输入 | 未经降维的输入、完整主干向量 | 交代宽度所指的对象 |
| 从缺口开始重发整个后缀 | 从缺失报文开始重发它及其后的所有报文 | 明确重传范围 |
| 装载生成权重和 KV 池 | 加载生成权重并分配 KV 池 | 区分数据加载和内存分配 |
| 未舍入时间 | 未经四舍五入的时间 | 使数值计算说明更自然 |
| 训练配方 | 训练配置 | 避免 recipe 的字面译法 |
| 质量概率 | 验收通过率、通过验收的概率 | 明确统计事件 |
| HTTP/3 是 HTTP 的传输映射 | HTTP/3 规定了如何在 QUIC 上传输 HTTP 请求和响应 | 用具体关系代替抽象直译 |

沿用用户的措辞偏好，将相关“装入”改为“加载到”；按语境区分“保留数据”“预留空间”“占用内存”。已有明确解释的专业术语，如归约、驻留、背压、强扩展等继续使用。模型和硬件的实际使用寿命仍称“寿命”。
