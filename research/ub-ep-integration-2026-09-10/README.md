## 算例与复现

```bash
python3 calculations/ep_skew.py
python3 calculations/parallel_choice.py
python3 calculations/supernode_scaling.py
python3 -m unittest discover -s calculations/tests -p 'test_ep_skew.py'
python3 -m unittest discover -s calculations/tests -p 'test_parallel_choice.py'
.venv-site/bin/python manuscripts/ub_ep_figures.py
.venv-site/bin/python scripts/build_site.py
.venv-site/bin/python scripts/check_site.py
```

三个计算脚本仅依赖Python标准库。图形复用现有Matplotlib/Numpy/思源黑体环境，每图输出SVG、PNG、PDF；章节build脚本已接入生成器。图号映射见 [figure-renumbering.json](figure-renumbering.json)。

所有新增计算都是教学模型而非新GPU测量。EP阶段总和只适用于整批屏障；流水要沿就绪依赖另算。1024卡训练固定全局token与更新工作，分别改变节点大小、本地带宽、出口上限；吞吐是串行阶段模型，不将全部通信预设为完美重叠。TP搜索只覆盖明示候选，不称任意模型的全局最优。

容错使用小故障率近似，恢复期间再次故障、检查点争用及相关故障分布未建模；输入和正文均明确说明。所有作业一致恢复与推理副本独立恢复分开讨论。
