## 计算主题

`calculations/src/infra_calc/topics/ub_fabric.py`，CLI 子命令 `ub-fabric`，场景在 `scenarios/book.json` 的 `ub_fabric` 下（默认、每台主机 64 个端点、1 MiB 缓存三种），结果在 `results/ub-fabric-*.json|md`，测试 `tests/test_ub_fabric.py`（5 项）。输入是声明的记录尺寸、阶段延迟、缓存容量与控制操作计数；论文仿真值只作对照，保存在模块常量 `PAPER_MEASURED_NS` 中，不参与推导。

```bash
python3 calculations/calc.py ub-fabric --format md
python3 -m unittest discover -s calculations/tests -p 'test_ub_fabric.py' -v
.venv-site/bin/python manuscripts/ub_ep_figures.py
```

七幅新图由 `manuscripts/ub_ep_figures.py` 生成，全部读取 `results/ub-fabric-book.json`，使用 `figure_style`。
