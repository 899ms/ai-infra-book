# 从硬件、模型与期限选择切分

运行：`python3 calculations/parallel_choice.py`。修改 [输入](../scenarios/parallel-choice-example.json) 后可用 `--scenario` 重算。

教学模型，固定 Qwen3-8B BF16；不代替真实引擎规划器。候选为 TP1/2/4/8 与剩余卡组成的独立实例；每实例一次处理一个会话，不做连续批处理或跨会话流水。
逐步时间复用第六章权重／KV 读取与 72 次 ring 归约模型；小批 decode 读取受限。跨机 TP 组保守地按组内每轮均受慢链路限制，不代表最优分层通信算法。
全部八卡从请求到达计费至所有请求完成，每卡每秒 1 成本单位；目标为满足最低按时比例后，最小化每个按时完成会话的成本。
每卡容量按均匀 TP 分片加复制的归一化权重、最大历史 KV 和固定工作区计。完整参数数值来自现有第六章算例。
候选最优只在上述模型和候选范围内成立。PP/CP/SP/EP、动态批处理、其他归约算法须先扩展工作与通信模型再比较。
