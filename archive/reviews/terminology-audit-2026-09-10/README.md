# 十二章术语与概念引入扫查（2026-09-10）

## 范围与方法

覆盖第 1—12 章的标题、正文、表格、图注，并提取全部 393 幅在用 SVG 的文字与正文对照。逐章检查首次出现语境和小节开头，定向检索中文简称、同义术语、重复替换与不自然断句。沿已有参考资料核对设计目的及系统名称。

修改放在使用位置：首次定义说明对象和用途；跨章的关键概念作简短回顾；同一英文在不同语境中分别解释。例如通信参与者的 rank 与 LoRA 的低秩维度不混用，计算后端与模型服务后端分别定义，通信请求槽位与数据缓冲区分别说明释放条件。

`edits.json` 保存本轮 150 条修改记录（包括后续修订和按章名称统一，不能当作独立概念数）。`first-occurrences.json` 是词法辅助索引，`figure-terms.json` 保存图内文字和未在正文匹配的标记；字面匹配用于发现候选项，定义是否充分按上下文审阅。

## 上下文术语统一

按用户后续意见，将模型语境中的“历史”统一为“上下文”：长度指 token 数，状态指已处理上下文的 KV 缓存、压缩表示或递推状态。第一章定义 context，第二章补充上下文与状态的区别。涉及任务过程的用“任务记录”“工具切换记录”；技术沿革、既往测量和优化器梯度历史保留原义。正文、表格、图注及绘图源同步修改，初次替换记录见 `context-edits.json`，随后按句子修订单位和措辞。

配图检查兼容 SVG 文本与轮廓字形；轮廓形式从文字组读取原标签，并检查该组确实包含字形路径或引用。
