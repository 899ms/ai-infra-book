# Same-Agent retained-page / checkpoint replay

Use the exact twelve Agent request prefixes and197 native page keys from cross-mac-traces-001. Sweep retained-page budgets0/64/256 independently for HBM, DRAM, local storage and remote storage (81 combinations). These are logical retention budgets in addition to a sufficient execution working set, not total physical GPU capacities; the earlier native pool scans remain the physical evidence.

Each tier is an inclusive page LRU. Search each required prefix page in HBM→DRAM→local→remote order; stop at the first page missing everywhere, because later pages are not a usable continuous prefix. After the request all required pages are available from compute/reuse and are admitted to HBM/DRAM in prefix order. Full policy checkpoints the complete current prefix every turn, periodic4 at turns4/8/12, recompute retains only volatile tiers. Worker-restart-persistent tiers are replicated when both have nonzero budgets. Existing-key checkpoint touches refresh LRU but do not rewrite bytes; streaming a prefix larger than capacity can evict its root. This is a defined reference policy, not claimed to reproduce native SGLang tree eviction.

For each capacity/policy combination replay normal operation, restart before turn7 (clear volatile tiers) and invalidation before turn7 (clear all logical indexes). These are replay events; previous native experiments provide actual restart/failure evidence. No live file or engine state is modified. Total729 scenarios,8748 request records.

Per-page local read/write-fsync times come from agent-storage-io. Remote RPC times come from the same Agent producer/consumer; unseen remote page reads use the observed GET median, with fallback counts retained. Timing is a synchronous checkpoint/barrier composition, not actual async overlap. For complete-prefix hits use measured per-input native GPU-warm request time, or the native host-recovery profile if host hits occur. For incomplete prefixes use measured full-cold recomputation median (conservatively no partial-prefill speedup modeled). Exact missing-token counts are still reported. These are calibrated timing proxies, not measured task completion, bandwidth-only costs or guaranteed bounds. The host profile is fixed per input, not proportional transfer scaling.

Record tier hits, request/token hit rates, logical write bytes, page RPC sums, first missing prefix, eviction counts and estimated completion. Sample quantiles repeat calibration data and are not independent production p95. All source hashes retained. V4 compressed/window state is a separate remaining accounting step; these pages are actual dense Qwen KV.

Persistence here means data remains available when the model worker restarts. The remote Mac HTTP store did not fsync its pages; local direct-write measurements include file/directory fsync. Therefore these two write latencies have different durability contracts and do not compare equivalent power-loss guarantees. No remote-store crash is modeled as survivable.
