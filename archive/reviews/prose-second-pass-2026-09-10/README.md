# 全书标题与中文表达第二轮复核

本轮接续 2026-09-10 的第一轮审校，检查当前前言及第 1—12 章的例题、练习、粗体提示和相关正文。覆盖清单包含 106 道练习及 512 处粗体文本；修改过程记录 171 项替换，其中包含对本轮改写的进一步润色，不等同于 171 个互不重叠的段落。

## 修订重点

- 标题说明对象、机制或所求问题，继续清理“突发、积压与容量”“切分、通信与流水”等仅列名词的标题。
- 题干写清执行顺序、计时起点、比较基准和物理量，删除重复引入与不明确的指代。
- 区分内存容量、累计访问量和累计内存占用，区分吞吐率、完成间隔和完整任务耗时。
- 将作为反例讨论的错误观点明确标为“误区”，避免脱离后文阅读时被误认为结论。
- 复核上轮改写的含义：实验 6-5 的准备是采用优化方案的额外成本；实验 11-8 比较两种服务处理相同任务量时的平均成功任务成本。

## 代表性修改

| 原表达 | 本轮表达 |
| --- | --- |
| 关键路径与状态寿命 | 工具并行与局部加速能节省多少任务时间 |
| 满足回本目标需要多少设备与请求需求？ | 在一年内回本需要多大的实际服务规模？ |
| 完成时间与优化开销 | 通信优化能节省多少时间，何时抵消准备开销？ |
| 保留哪个前缀？ | 有限缓存应保留哪些前缀，才能节省最多时间？ |
| 预热提前量与预测准确率的等待收益和内存代价 | 提前准备环境能省多少等待，又占用多少内存？ |
| 槽 A 才能覆盖成下一个块 | 才能将下一块数据写入槽 A，覆盖原有内容 |

练习 3-4 的两组情景分别说明：先计算工具串行、并行时的任务耗时与累计状态占用；再明确引用本节代码任务的实测记录，计算首轮模型加速和工具加速的收益。复算结果为 21／15 秒、16／10 GiB·s，以及节省 27.28125／0.039 秒。
