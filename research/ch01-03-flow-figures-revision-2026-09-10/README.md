# 前三章段落衔接与配图修订

本轮接续中文语句修订，仅修改前三章正文及其配套绘图、阅读版与检查资料。修改前正文和生成程序保存在本目录；edits.json 记录首轮 43 项段落与插图调整，最终差异以正文与快照对照为准。

## 讲解顺序

第一章沿容量、放置、读取、耗时与批量复用展开，再将资源分析引向 TPU、SmartNIC 与设备互联。第二章从宏观结构进入矩阵尺寸，区分一步读取与整段生成的累计读取，再比较历史表示、专家复用与完整模型。第三章依次从单请求指标走向到达分布、多轮缓存、额外生成与验证、工具反馈、多模态时序、训练更新、RL 样本与长期成本。衔接段说明后一问题如何由前一问题产生，同时删除重复的引入。

## 校验

check_flow.py 核对章节顺序、表格内容、图号顺序、脚注、链接、生成段落及新增图中的数量关系。模型表继续由 verify_tables.py 校验，并运行既有 check_revision.py 与第二、三章独立验证。check_browser.py 检查 1440／390 像素下的图片、公式、目录与页面宽度。具体结果见 flow-validation.json、browser-review.json 及各章 validation.json。

最终结果：199 项衔接与配图检查、77 项模型表检查、75 项既有修订检查通过。第二、三章独立验证通过；三个阅读版在桌面和手机宽度下均无页面溢出、图片加载失败或公式错误。新增图已逐图查看，并修正递推图的文字与箭头交叠。完整正文差异见 manuscript.diff。
