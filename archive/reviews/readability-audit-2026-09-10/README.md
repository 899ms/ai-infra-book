## 主要修订

1. **批量与延迟的概念关系。** 练习 1-3 的结尾原来暗示增大 batch 可以不断降低单请求延迟；现改为解释为什么每个输出分摊的时间减少，并不意味着单请求的单步延迟缩短。
2. **标题中的对象与结果。** 将“从专家选择到设备负载”“压缩后完成任务的成本”“AI 助手的跨设备分工”等概括过宽的标题，改为明确描述专家分派、KV 压缩、视觉编码位置与状态迁移的标题；同时明确其影响的负载、容量、正确性或耗时。
3. **自然的中文语序。** 将“将 Qwen3-VL-4B 图片从……”改为改变输入图片的分辨率；将“将 GPU 小时分配给设备”改为在固定总训练用量下比较设备规模与完成天数；将“将这个关系放回平台”改为直接引出代码修复平台的突发工具调用。
4. **清楚的比较条件。** 明确每条序列最后一个位置的词表投影、单请求的前缀复用比较、生成阶段新增 KV、教师模型与生成模型结构相同，以及工具相互独立。
5. **相互独立的优化情景。** 练习 8-8 明确第二组优化从原始任务出发，并以耗时减半、降至四分之一表达加速效果；习题 10-7 明确异步保留率与不丢弃样本的同步基准。
6. **长题干的执行顺序。** 实验 11-2 按计时起点、释放环境、保存快照、重建或恢复的顺序分段说明，明确哪些阶段计入内存驻留；练习 12-8 分开说明故障范围、运行状态、任务进度及计费条件。
