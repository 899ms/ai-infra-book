# 实验 9-2：A100＋H20 的 PD 分离

对应正文 9.2。分开 prefill 和 decode 的收益何时被抵消？以 A100 80GB SXM 做 prefill、H20 SXM5 96GB 做 decode，比较共置、同构 PD、异构 PD 与角色对换；沿同一 Qwen3-8B 扫描输入长度、输出长度、缓存命中、到达率与池规模。

## 独立运行

```bash
python3 run.py    # 现场调用 calculations/calc.py pd-pool
```

只需 Python 3.8+ 标准库。每张卡的阶段能力由[硬件表](../../../calculations/results/hardware.md)峰值乘 50% 效率、经 Qwen3-8B 逐算子账的 Roofline 推出：A100 80GB SXM 为 312 TFLOP/s、2039 GB/s，H20 SXM5 96GB 为 148 TFLOP/s、4096 GB/s（MegaScale-Infer 表 3）。50% 以第 8 章 RTX PRO 6000 批量 64 的实测输出间隔校准（带宽约为峰值的 49%）。decode 批量 32，链路 25 GB/s。工具会在给定卡集合里自动选最优分工，因此“角色对换”与异构 PD 属同一次求解；第四个布局换成“全 H20”作为另一端对照。

## 结果（节选，到达率 3.5 请求/s）

| 布局 | 场景 | PD 上界 | 共置上界 | PD/共置 | 最优分工 |
| --- | --- | ---: | ---: | ---: | --- |
| 八张 A100 | 8K／1024 | 2.83 | 3.05 | **0.93×** | P:A100×3 D:A100×5 |
| **四 A100＋四 H20** | 8K／1024 | **4.55** | 3.02 | **1.51×** | P:A100×4 D:H20×4 |
| 四 A100＋四 H20 | 8K／128 | 6.33 | 5.84 | 1.09× | P:A100×4,H20×3 D:H20×1 |
| 四 A100＋四 H20 | 8K／4096 | 1.26 | 1.15 | 1.10× | P:A100×2 D:A100×2,H20×4 |
| 四 A100＋四 H20 | 8K／1024，命中 6K | 5.69 | 4.90 | 1.16× | P:A100×2 D:A100×2,H20×4 |
| 四 A100＋四 H20 | 32K／1024 | 0.90 | 0.69 | 1.31× | P:A100×4,H20×1 D:H20×3 |
| 八张 H20 | 8K／1024 | 2.77 | 2.98 | 0.93× | P:H20×5 D:H20×3 |

四条判断：

1. **同构 PD 不提高吞吐（0.91–0.99×）**。一个请求在分离前后消耗同样的资源秒，整数划分还让两池能力无法相等。同构分离的价值在延迟隔离：A100 上一次 8K prefill 约 0.86 秒，共置不分块时会让在途请求错过约 16 个 decode 步。
2. **异构 PD 在推理型请求上收益最大**。8K 输入、1024 输出时，A100 做 prefill、H20 做 decode 达到 1.51×；角色对调只剩 2.22 请求/s。H20 的算力不到 A100 一半、带宽约为两倍，两阶段的强弱恰好相反。
3. **输出过短或过长，收益都会缩小**。128 输出时 decode 很轻，三张 H20 转去做 prefill，只剩 1.09×；4096 输出时 decode 占绝对多数，两张 A100 也要转去做 decode，只剩 1.10×，此时八张 H20 单独部署（1.261 请求/s）已与异构组合持平。
4. **分块捎带是同构集群的主要对手**。A100 一步 decode 的空闲算力可捎带约 490 个 prefill token，理想重叠下八张 A100 共置上界 4.50 请求/s；H20 只能捎带约 85 个，四加四理想共置为 4.17 请求/s，仍低于异构 PD 的 4.55。

完整 24 组数值见 [results/pd.md](results/pd.md)；每个 `results/pool-*.json` 的 `derived_stage_rates` 字段列出逐卡的计算量、读取量和 Roofline 两项时间。

## 限制

- 阶段能力是峰值乘统一效率的 Roofline 下界推算，不是 A100／H20 上的实测；效率随批量和内核变化，改 `compute_efficiency`、`bandwidth_efficiency` 即可重算。
- 只算稳态上界（吞吐），不含排队分布、首 token 与逐 token 延迟的尾部；SLO 判定见实验 8-9。
- 费用未计入：两种设备的单价与功耗需要另一组输入。
- 未含受支持 PD connector 的真实系统 trace 与时段尾延迟。
