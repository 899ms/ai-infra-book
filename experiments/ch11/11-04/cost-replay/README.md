# 抢占恢复的费用敏感性：实测窗口与教学价格分开

本增量对应历史11-5。run.py读取同一组质量已验收的12条真实Mac生成／中断／恢复记录，核验每条生成计数、管理器唯一token与重复投递守恒，输出实际KV前缀重建token。completed_training_tokens保留null：这些记录没有优化器消费或更新回执，不能将管理器收到等同完成训练。

为比较相同完成样本，明确假设整段资源从首次worker创建到最终退出按1教学费用单位/小时收费，费用=实测wall_s/3600；该价格不是服务商报价，wall_s不是GPU忙碌时间。文件中同时保存无量纲价格临界比，便于替换真实价格。

| 任务／抢占K | 保留相对重启节省秒 | 保留方案价格/重启价格的回本上限 |
|---|---:|---:|
| sequence／32 | 1.764179 | 1.189318 |
| sequence／96 | −1.181214 | 0.907718 |
| extract／32 | 0.128345 | 1.012728 |
| extract／96 | 2.062878 | 1.185609 |

这些是同任务、同K的实跑窗口配对；单次路径含加载／主机噪声，不证明稳定加速。sequence/K96保留更慢，同价更贵，须至少约9.23%单价折扣才回本。省掉重复采样不等于省掉模型工作，KV重建仍有实际token和耗时。与不中断基线的重启／保留价格上限也逐行保存。

额外资源的存活阈值单列**教学模型**：权重4351884216bytes从model-identity.json读出，声明有效网络1GB/s、生成100token/s、固定资源1单位/h、额外资源0.3单位/h，不计其他初始化。准备p=4.351884216s；存活L的生成预算100max(0,L−p)。只比较同量的生成工作与已准备固定资源，0.3L < L−p要求L > p/0.7=6.216977451s。脚本扫描2／5／10／20／40s，2s无产出、5s虽产出但更贵、10s及以上在该模型中更便宜。

该阈值没有把部分响应自动转为有效训练样本：是否完整、是否通过验证、是否实际进入训练均未知；相应字段null。还没有实测新增资源与原资源同时rollout、权重网络加载或训练联动，因此不关闭历史11-5缺口。教学模型提供可复算条件，不代替这些记录。

复算：`python3 experiments/ch11/11-04/cost-replay/run.py`。results.json含来源SHA、逐路径计数与费用、比较临界比和全部教学扫描。没有修改旧原件或调用外部付费服务。
