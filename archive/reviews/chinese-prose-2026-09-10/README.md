# 全书中文润色与第二遍复读记录

本次工作覆盖 `manuscripts` 中的前言和第 1—12 章。首轮逐章修改后，根据用户“再仔细阅读一遍全文”的要求，第二遍重新通读正文、表格、图注、练习和脚注，并回查修改后的表述。

第二遍记录了 272 组具体替换，其中包含对少量句子的再次调整；这是编辑记录条数，不是互不重复的问题数。修改直接写入正文。

## 修改重点

- 补全动作主体、比较对象和计量对象，例如区分内存容量与累计内存占用、计算耗时与完成时刻。
- 调整不自然的搭配、重复表述和过度压缩的长句，使条件、动作和结果衔接清楚。
- 消除倍数表述的歧义，例如把“维度扩大一倍，元素数扩大四倍”改为“维度增至两倍，元素数增至四倍”。
- 让叙述与公式的边界条件一致，例如在 `c <= v` 条件下，将“低于”改为“不高于”。
- 明确音频生成、数据到达与实际播放的区别，以及会话恢复时需要重算或重新生成的对象。

## 记录与归属

- `before/`：首轮开始时的快照。
- `second-pass-before/`：第二遍开始时的快照。
- `language-edits.json`：首轮可独立核对的精确替换记录，不代表首轮全部改动。
- `second-pass-edits.jsonl`：第二遍逐项记录的替换前后文本。
- `*.diff`、`*.second-pass.diff`：对应快照与检查时正文的差异。
- `second-pass-validation.json`：精确替换保护检查及正文结构检查结果。

工作区同时存在其他编辑，因此快照差异也包含同期新增、重写和调整，不能全部归因于本次润色。部分已记录的替换后来被进一步修订；编辑日志用于追溯操作，当前正文为最终阅读版本。
