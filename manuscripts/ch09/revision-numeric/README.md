# 第九章：用数字推进论证

本轮保留七节、24小节与10道练习，系统修改正文论述、精度和九幅插图。

- 以同一组条件展开：64个token、512分派、128个36 MiB专家，比较4行／64行输入及4.5 GiB／288 MiB读取，再将任务放到八卡，解释复用与最忙设备之间的冲突。
- 给出PD配比的中间步骤：命中后P能力增加四倍，为何两个A留在P、其余转D；长输出后为何只留一个A。
- 从200 ms目标逐项扣除10 ms剩余计算、10 ms查找及48.3 ms本地搬移，得到远端读取约131.7 ms预算与9.2 GB/s等时带宽。
- 迁移例题保持16.45 GB原载荷，另给5／25 GB/s有效带宽及9秒串行准备，说明五倍网络速度仅缩短约21%的完整时间。该段为明确条件计算，不替换原冻结场景。
- 正文保留配置维度、页数、调用数和27批、78／79等整数边界。约12.4 ms附近的交点不以额外小数暗示实测精度；精确原值与版本条件进入注释。
- 将准备核验、输出一致和适用范围等资料放到相应脚注。必要的路径、数据身份、容量和质量条件仍留在论证发生处。
